A full scene Loader for wobbly life
Use it by clicking "F11" Then do what you wish, if a scene does not load, load another scene or exit the game and restart it

Install:
Make sure you have bepinex 5.4 installed
download the dll from the Releases page
put your dll into "C:\Program Files (x86)\Steam\steamapps\common\Wobbly Life\BepInEx\plugins"
Launch the game
You have it installed
